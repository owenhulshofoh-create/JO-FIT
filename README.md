# JO FIT 5.3

**JO FIT – Jouw fitness app. Naar een idee van Owen en Jonathan.**

Overzichtelijke fitness-PWA voor persoonlijk trainen, powersets, oefeninstructies, logboek en progressie. Met een aanvullende pagina over alcohol, drugs en sport en 24 aangeleverde oefenfotos bij 23 oefening-ID's.

Dit is een **statische GitHub Pages-website** met een optionele cloud- en AI-serverconfiguratie. Persoonlijke browsergegevens worden **niet** met deze broncode naar GitHub geüpload. Bewaar eerst een persoonlijke back-up vóór je de website bijwerkt.

**Begin bij `START-HIER.md`** voor de volledige installatie-instructies en status. `TESTRESULTATEN.md` beschrijft welke controles daadwerkelijk zijn uitgevoerd.
