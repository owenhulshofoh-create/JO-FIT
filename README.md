# JO FIT 5.0 — Smart Fitness Coach (fase 1)

**Jouw fitness app · Naar een idee van Owen en Jonathan**

Start bij **[START-HIER.md](./START-HIER.md)**. Dit is een volledig GitHub Pages-project, geen scriptfragment.

**Direct beschikbaar zonder account:** overzichtelijke navigatie met vijf onderdelen, lokale intake met materiaalcontrole, voorgestelde schemaversies, 59 oefeningen, Duo op één apparaat, persoonlijk logboek, voedingsdagboek met echte hoeveelheden en back-ups.

**Nog niet live geconfigureerd:** gratis cloudaccounts via Supabase, echte AI-chat, externe productzoekfunctie, accountverwijderingsfunctie. **Nog niet gebouwd:** echte video-techniekherkenning, gevalideerde 3D-animaties voor 59 oefeningen en Duo-sync over twee apparaten. Voor meer details: [STATUS-EN-VERVOLG.md](./STATUS-EN-VERVOLG.md).

Voor het publiceren van updates: GitHub Desktop gebruiken zoals beschreven in START-HIER.md. De bestaande JO FIT-website hoeft niet opnieuw te worden aangemaakt.
